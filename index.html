How to read this

Each task shows three separate things: when it last fired, the result the scheduler recorded, and whether its output was verified.

Ran OK: the scheduler recorded a successful run.

Unknown: no result was read. Never treated as success.

Failed: stays failed until a later run is recorded as succeeded.

First run pending: new task that has not run yet.

Status comes from Claude's own scheduler by way of the shared ledger. Nothing here creates, starts or changes a task.
