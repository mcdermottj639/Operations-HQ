# Sync contract

The public page follows this file. The scheduled task does not, until the chat that owns Claudex sync applies the paste in the Drive doc "Operations HQ — sync contract (paste)".

## Two gears

No new task and no fewer runs.

- 10:55 AM, 2:55 PM, and 10:55 PM ET rewrite the task table from the scheduler only: last fired, recorded result, verified unknown unless that run itself checked evidence. They do not open handoff docs, repos, or pull requests.
- 6:55 AM and 6:55 PM ET keep the deep pass: doc fingerprints, repo SHAs, and OPS items.

## Do not retry a blind spot

Scheduled runs cannot fully read pull requests. Say that once. Do not leave an open blocker that tells the next run to retry.

A task that stores no result stays Unknown. That is its normal state. Do not list those tasks as an open blocker.

## Device acceptance

A release that does not change layout does not reopen a phone check. A layout change is one check-off. Only Jack can clear it.

## Prompt size

An edit to the sync prompt must make that prompt shorter. Do not copy rules that already live in `CLAUDE.md`.

## What the page does now

On a weekday, once a market task's first fire has passed, an OK from before that fire is shown as Unknown. A snapshot taken after the fire still counts. The 6:55 PM ledger is enough for the 9:10 PM publish. A snapshot older than 26 hours still marks every OK as Unknown.
