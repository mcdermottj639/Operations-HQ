# Operations HQ

Jack's read-only operations dashboard: Overview, Projects, Tasks, Decisions, Sources.

- One static page (`index.html`), no build step, no backend, no external requests.
- Published with GitHub Pages from `main` (root). **The page is public.** Keep account values, tokens, buyer details and finance records out of it.
- Data is a hand-audited snapshot (currently Nov 16, 2026), labeled as such on the page. It is not live task telemetry.
